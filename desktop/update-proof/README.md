# Local update proof

The phase-1 update mechanism is intentionally local and file based. It does not
call SharePoint, Graph, Firebase, Dropbox or any hosted runtime.

The package format is:

- `manifest.json` with `packageVersion`, `baseVersion`, compatible runtime and
  schema versions, component entries, explicit deletions and hashes.
- `payload/` containing only changed files.
- detached signature generated by an offline organisation-controlled key.

Acceptance checks for the prototype:

- reject wrong-base packages;
- reject corrupt or tampered payloads;
- stage into a new versioned app directory;
- apply explicit deletions;
- keep the previous compatible version available for rollback;
- preserve local application data unless the user explicitly asks to remove it;
- keep a full installer repair path for runtime or bootstrapper changes.

Tauri's standard updater is not treated as proof of component-level updates.
